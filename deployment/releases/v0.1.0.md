# 0.1.0 — 2026-07-22

## Added

- Stage 01 — Schema Definition & Validation.
- Stage 02 — Raw Ingestion for CMS POS + QIES datasets.
- Stage 03 — Data Quality Profiling (nulls, duplicates, drift indicators).
- Stage 04 — Reporting Layer producing dataset summaries, column health, facility metrics.
- Makefile workflow for stage execution, diagnostics, tests, and cleanup.
- Logging system (ingestion, quality, runner) using YAML configuration.
- Full test suite across Stages 01–04.
- Diagnostics scripts for each stage.
- Repository structure and environment setup (`environment.yml`).
- Pipeline architecture and schema overview diagrams.

## Changed

- Updated root README to include Stages 01–04.
- Improved Makefile reset target.
- Standardized directory structure for data, logs, and artifacts.
- Unified logging configuration across all stages.

## Fixed

- POS/QIES dtype inconsistencies in ingestion.
- Stage 03 missing‑key behavior for facility identifiers.
- Stage 04 manifest generation edge cases.
- Facility health classification inconsistencies.

## Removed

- No removals in this release.

## Deprecated

- No deprecated components in this release.

## Security

- Initial logging hardening (no PII, structured logs).
- Basic environment isolation via `environment.yml`.

## Observability

- Added ingestion, quality, and runner logs.
- Added basic diagnostics for schema, ingestion, and quality.

## Provenance

  - `pipeline_version: 0.1.0`

  - `manifest_version`
  - `deployment_version: 0.0.0` (deployment not yet introduced)
