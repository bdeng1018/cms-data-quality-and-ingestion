# 1.0.0 — 2026-08-02

## Added

- Full deterministic deployment subsystem (Dockerfile, root-level Compose, Makefile.deploy).
- Provenance validator (`validate_provenance.py`) ensuring manifest correctness.
- SBOM validator (`validate_sbom.py`) enforcing component integrity and version compliance.
- Audit log generator (`generate_audit_logs.py`) producing structured, deterministic audit artifacts.
- Drift detection workflow (Terraform + Helm diff) integrated into deployment Makefile.
- Governance, compliance, access control, and risk documentation.
- Security hardening guidelines (`HARDENING.md`) and policy definitions.
- Incident response playbook (`INCIDENT_RESPONSE.md`).
- CI/CD pipeline (`deployment/ci/github-actions.yml`) for validation, testing, and release automation.
- Helm chart (`deployment/helm/`) and Kubernetes manifests (`deployment/k8s/`).
- Terraform module (`deployment/terraform/`) for infrastructure provisioning.
- Logging + monitoring stack (Fluent Bit, Prometheus, Grafana dashboards).
- Deterministic pipeline execution across local, Docker, Compose, and CI/CD.
- Updated root README and deployment documentation.

## Changed

- Unified deployment validation workflow (`provenance`, `sbom`, `audit`, `drift`).
- Standardized directory structure for deployment artifacts.
- Normalized versioning across pipeline, schema, artifacts, manifests, and deployment layers.
- Improved CI workflow to run deployment validation before merge and release.

## Fixed

- SBOM component version mismatches.
- Manifest semantic-version validation failures.
- Drift detection false positives caused by Helm value overrides.
- Audit log formatting inconsistencies.
- CI workflow failures due to missing deployment environment variables.

## Removed

- Legacy deployment scaffolding from early Branch 1 development.

## Deprecated

- No deprecated components in this release.

## Security

- Updated hardening rules and container security posture.
- Added PSP/NetworkPolicy definitions for Kubernetes deployment.
- Added deterministic access control contract.

## Observability

- Added metrics, alerts, dashboards, and logging configuration.
- Integrated Fluent Bit, Prometheus, and Grafana dashboards.
- Standardized observability directory structure.

## Provenance

- Updated `manifest.provenance` to include:
  - `pipeline_version: 1.0.0`
  - `schema_version`
  - `artifact_version`
  - `manifest_version`
  - `deployment_version: 1.0.0`
  - `sbom_version`
- Ensured deterministic version propagation across all layers.
