## 3. Data Type Rules

All fields are treated as:

| Type | Description |
|------|-------------|
| string | UTF‑8 text, trimmed and normalized |

No semantic typing (date, boolean, float) is applied.

---

## 4. Required Field Rules

A field is **required** if:

```python
df[col].isna().sum() == 0
```

This is the authoritative rule.

## 5. Schema Evolution Rules

Stage 01 regenerates the schema automatically.
To maintain stability:

### Adding a field

- Add to Stage 02 cleaned dataset
- Regenerate Stage 01
- Update this document

### Removing a field

- Remove from Stage 02 cleaned dataset
- Regenerate Stage 01
- Update this document

### Renaming a field

- Update Stage 02 cleaning logic
- Regenerate Stage 01
- Update this document
